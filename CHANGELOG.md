## [0.1.0]

First release ready for Chrome Web Store submission.

### Added

- **Quick Capture Popup:** Autofocus and Enter-to-save, with customizable global keyboard shortcut (`Ctrl/Cmd+Shift+Y`).
- **Composer Micro-Toolbar & Tab Clipping:** One-click active tab link capture (`[Title](URL)`), formatting buttons for checklists, bullets, bold, and code, with smart checklist continuation on `Shift+Enter`.
- **Interactive Checklists & Rich Markdown:** Clickable checkboxes (`- [ ]` / `- [x]`), bullet lists, clickable URLs, bold text, and code blocks.
- **Hashtag System & Filter Chips:** Automatic hashtag detection (`#tag`), clickable inline pills, and a horizontal tag filter bar.
- **Note Color Accents:** 6 curated Apple-grade color tints (Warm Amber, Mint Emerald, Ocean Blue, Soft Purple, Rose Quartz, and Default).
- **One-Click Note Duplication:** Instantly duplicate notes from the 3-dots actions menu.
- **Reminders & Live Countdown:** One-tap presets, custom date picker, persistent desktop notifications with snooze/mark-done, badge counter, and live imminent relative countdown (`in 45m`).
- **5 Theme Modes:** System, Light, Dark, OLED Pure Black, and Warm Sepia.
- **Bilingual & RTL Support:** Full English and Persian (فارسی) translations with automatic RTL layout switching.
- **Data Portability:** Full JSON backup & merge-on-import, plus one-click Markdown (`.md`) export.
- **Flexible Monetization:** 10 free notes, with Monthly ($1/mo) and discounted Annual ($10/yr, -17%) Pro tiers via ExtensionPay.
- **Zero-Host-Permission Privacy:** Strictly client-side storage (`chrome.storage.local`), zero tracking, zero invasive permissions.
- **Comprehensive Quality:** 232 unit and component tests passing, 100% type-safe, ESLint + Prettier verified.
